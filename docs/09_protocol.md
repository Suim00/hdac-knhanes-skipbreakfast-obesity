## 1. 연구질문(PECO)

우리나라 성인에서 아침 결식은 아침 식사를 하는 경우에 비해 비만 유병과 연관되는가?

| 연구질문(PECO) |
|---|
| P : 우리나라 성인(만 19세 이상, 2024년도) |
| E : 아침 결식 |
| C : 아침 식사를 하는 경우 |
| O : 비만(BMI 25 kg/m^2 이상) |

예상 방향: 결식 빈도가 높을수록 비만 유병이 높을 것(위험을 높이는 방향) 아침을 거르면 이후 끼니에서 과식하거나 간식, 야식이 늘 수 있고 식사의 질이 떨어지며 식사 시간 불규칙이 식욕과 에너지 대사에 영향을 줄 수 있기 때문입니다.

- 역방향 인과 : 체중을 줄이려고 아침을 거르는 사람은 이미 비만이거나 체중이 늘어난 사람일 가능성이 큽니다. 이 경우 비만이 결식의 원인이 됩니다. 성인 전체로 범위가 증가한다면 질병 때문에 체중이 줄거나 식욕이 떨어진 고령자도 포함되어 방향이 달라질 수 있습니다. 때문에 체중조절 노력을 공변량 후보로 넣었습니다. 체중조절 노력이 결식의 결과일 가능성도 있어서 넣은 모형과 뺀 모형을 비교하는 민감도 분석을 하여 대응합니다.

## 2. 자료와 가중치

| 항목 | 내용 |
|---|---|
| 사용 자료 | 국민건강영양조사 제9기(2022-2024) 중 2024년 (단일 연도) |
| 사용 파일 | 2024년 기본DB(건강설문조사, 검진조사, 영양조사 공통) SAS 파일 `hn24_all.sas7bdat` (지침서상 `HN24_ALL`). 저장 위치: `MyDrive/hdac_data/HN24_ALL(SAS)/hn24_all.sas7bdat` |
| 가중치 변수 | `wt_tot` (건강설문-검진조사 & 영양조사 가중치) (이용지침서 94쪽, 표 6-2 28쪽) |
| 층 변수 | `kstrata` (분산추정 층) (이용지침서 94쪽, 설명 35쪽) |
| 집락 변수 | `psu` (조사구번호, 표본설계 시 1차 추출단위) (이용지침서 93쪽, 설명 35쪽) |

**가중치 선택 이유**
- 이용지침서는 여러 조사 부문의 변수를 함께 분석할 때 변수들이 속한 부문을 모두 고려한 연관성분석 가중치를 선택하도록 안내한다 (이용지침서 24쪽, 표 6-2).
- 노출인 아침식사 빈도(`L_BR_FQ`)는 영양조사의 식생활조사 부문 변수이다 (이용지침서 218쪽).
- 결과인 비만(`HE_BMI`, `HE_obe`)은 검진조사 부문 변수이다 (이용지침서 179쪽).
- 연령, 성별, 교육, 소득, 흡연, 음주 같은 공변량은 건강설문조사 부문 변수이다.
- 세 부문의 변수를 함께 사용하므로 표 6-2의 "건강설문 AND 검진 AND 영양" 행에 해당하며, 제9기(2024)의 가중치는 `tot`, 즉 `wt_tot`이다. 건강설문·검진조사 가중치(`wt_itvex`)와 영양조사 가중치(`wt_ntr`)는 한 부문의 변수만 사용할 때의 가중치이므로 사용하지 않는다.

**복합표본 설계 반영**
- 분석 시 `wt_tot` 가중치, `kstrata` 층, `psu` 집락을 모두 지정한다.
- 성별, 연령대 등 일부 집단만 볼 때도 자료를 잘라내지 않고 도메인 분석으로 진행한다.

**자료 사용 원칙**
- 한 팀에 자료 하나만 사용하며, 다른 조사 자료와 섞지 않는다.
- 원시자료는 저장소에 올리지 않고, 팀원이 각자 신청해 받아 자기 Google Drive의 `MyDrive/hdac_data/`에만 둔다.

**자료 확인 결과 (code/09_data_check.ipynb 출력 기준)**
- 파일 전체 6,997명, 변수 813개
- 핵심 변수 11개(age, sex, HE_prg, L_BR_FQ, HE_ht, HE_wt, HE_BMI, HE_obe, wt_tot, kstrata, psu)와 공변량 6개(town_t, educ, sm_presnt, dr_month, N_DIET, N_EN)가 모두 파일에 있음
- L_BR_FQ 원 코드별 인원(전체 참여자): 1 주 5~7회 4,214명, 2 주 3~4회 669명, 3 주 1~2회 786명, 4 거의 안한다 1,136명, 결측 192명 (9 모름/무응답은 없음)
- `HE_prg` 코드별 인원: 0(아니오) 3,911명, 1(예) 16명, 8(비해당, 남자) 3,070명
- `wt_tot` 결측 192명, 0 이하 0명
- `HE_obe` 결측 1,088명 (비임신자만 값이 있음)
- `kstrata` 27개 층(결측 0), `psu` 192개 집락(결측 0)
- 최종 분석대상 5,749명 중 `HE_obe` 결측 0명

## 3. 변수 정의표


| 구분 | 구성개념 | 분석용 정의 | 비해당 및 무응답 처리 | DAG 역할 | 원변수명 |
|---|---|---|---|---|---|
| 노출 | 아침식사 빈도 | 거의 매일(비교군) 대비 결식 빈도 높은 단계별 범주 | 비해당 / 무응답 / 모름 $\rightarrow$ 결측 처리 및 분모 제외 | 주 노출 요인 | L_BR_FQ |
| 결과 | 신장 |측정된 신장 (cm) | 검진 미참여, 임신 중 -> 제외 | 검진 미참여 $\rightarrow$ 결측 | 비만도(BMI) 산출 기초 자료 | HE_ht |
| 결과 | 체중 | 측정된 체중 (kg) | 검진 미참여 $\rightarrow$ 결측 | 비만도(BMI) 산출 기초 자료 | HE_wt |
| 결과 | 체질량지수 | $\text{체중(kg)} / [\text{신장(m)}]^2$ | 검진 미참여, 임신 중(HE_prg) $\rightarrow$ 분석 대상 제외 | 주 결과 변수 (Continuous) | HE_BMI |
| 결과 | 비만 여부 | BMI 25 이상 = 1, 미만 = 0 (또는 지침서 기준) | 검진 미참여, 임신 중(HE_prg) $\rightarrow$ 분석 대상 제외 | 주 결과 변수 (Binary) | HE_obe |
| 선택 보정 | 임신 여부 | 임신 중 = 1, 해당 없음/남성 = 0 등 | 무응답 $\rightarrow$ 결측 | 임신부 대상자 제외(Exclusion) 기준 변수 | HE_prg |
| 공변량 | 나이 | 연속변수 (세), 만 19세 이상 | 없음 | 교란요인 보정 (Confounder) | age |
| 공변량 | 성별 | 여성 = 1 (또는 남성 기준) | 없음 | 교란요인 보정 (Confounder) | sex |
| 설계 변수 | 총표본가중치 | 국민건강영양조사 분석용 가중치 | 무응답/결측 시 제외 | 복합표본 분석 (Survey Weight) | wt_tot |
| 설계 변수 | 층화변수 | 복합표본 설계 층화(Strata) 변수 | 해당 없음 | 복합표본 분석 (Stratification) | kstrata |
| 설계 변수 | 집락변수 | 원추추출단위(Primary Sampling Unit) | 해당 없음 | 복합표본 분석 (Cluster) | psu |
| 매개 후보 | 야식 및 간식 섭취 | 기본 모형에는 넣지 않음 직접효과 민감도에서만 추가 | 문항 없음 | 매개 후보 | 존재 하지 않음 | 
| 매개 후보 | 총에너지 섭취 | 기본 모형에는 넣지 않음 직접효과 민감도에서만 추가 | 영양조사 비참여 -> 결측 | 매개 후보 | N_EN |

교란인지 매개인지 애매한 변수의 입장 
- 신체활동은 식습관과 체중의 공통 원인이므로 교란으로 보고 기본 모형에 포함합니다. 결식이 활동량을 바꾸는 경로(매개)도 완전히 배제할 수 없어서 신체활동을 뺀 모형으로 민감도 분석을 합니다.
- 야식 및 간식은 아침을 거른 뒤에 생기는 행동이므로 매개로 보고 총 효과 모형에서 제외합니다.

## 4. 분석 대상 선정 계획

출발 대상은 설문조사에 참여한 모든 인원이며, 다음과 같은 순서로 분석 대상을 선정합니다. 제외 대상은 삭제하지 않고 표시 변수로 처리해 도메인 분석을 시행합니다.

| 단계 | 기준 | 이유 | 인원 |
|---|---|---|---|
| 0단계 | 전체 조사 참여자 | 출발 대상 | 6,997명 |
| 1단계 | 만 19세 이상 성인 | 연구 대상(P) 정의 | 6,033명 |
| 2단계 | 임신 중인 여성 제외 | 임신은 체중과 식사 양상에 영향 | 6,017명 |
| 3단계 | 아침 식사 문항 응답자 (L_BR_FQ 1~4, 9·결측 제외) | 노출(E) 정의 불가 | 5,843명 |
| 4단계 | 신장·체중·BMI 결측 제외 (BMI 이상값 기준은 적용하지 않음) | 결과(O) 정의 불가 | 5,749명 |
| 5단계 | 가중치, 층, 집락 변수가 유효한 자료 | 복합표본 분석 필요 | 5,749명 |
| 최종단계 | 최종 분석 대상 | - | 5,749명 |

노출은 이분형으로 정의하였다. 최종 분석 대상 5,749명 중 아침 식사군(비교군)은 4,063명, 결식군(노출군)은 1,686명이다. 이 중 비만(BMI 25 이상) 비율은 비가중 기준 각각 36.0%, 37.7%이며, 이는 가중치를 적용하지 않은 기술통계이다. 결식과 비만의 관련성은 가중치·복합표본설계와 교란변수 보정을 적용한 분석 결과로 해석한다.
공변량 결측 처리(educ 88·99, N_DIET 9를 결측 처리) 후 공변량이 모두 있는 대상자는 5,600명이며, 149명은 회귀분석에서 제외될 수 있다.
