P : 우리나라 성인(만 19세 이상, 2024년도)
E : 아침 결식
C : 아침 식사를 하는 경우
O : 비만(BMI 25 kg/m^2 이상)

2. 자료와 가중치

| 항목 | 내용 |
|---|---|
| 사용 자료 | 국민건강영양조사 제9기(2022-2024) 중 2024년 (단일 연도) |
| 사용 파일 | 2024년 기본DB(건강설문조사, 검진조사, 영양조사 공통) SAS 파일 (지침서상 `HN24_ALL`). 저장 위치: `MyDrive/hdac_data/HN24_ALL(SAS)/` 폴더 안 [hn24_all.sas7bdat] |
| 가중치 변수 | `wt_tot` (건강설문-검진조사 & 영양조사 가중치) (이용지침서 94쪽, 표 6-2 28쪽) |
| 층 변수 | `kstrata` (분산추정 층) (이용지침서 94쪽, 설명 35쪽) |
| 집락 변수 | `psu` (조사구번호, 표본설계 시 1차 추출단위) (이용지침서 93쪽, 설명 35쪽) |

**가중치 선택 이유**
- 이용지침서는 여러 조사 부문의 변수를 함께 분석할 때 변수들이 속한 부문을 모두 고려한 연관성분석 가중치를 선택하도록 안내한다 (이용지침서 24쪽, 표 6-2).
- 노출인 아침식사 빈도(`L_BR_FQ`)는 영양조사의 식생활조사 부문 변수이다 (이용지침서 218쪽).
- 결과인 비만(`HE_BMI`, `HE_obe`)은 검진조사 부문 변수이다 (이용지침서 179쪽).
- 연령, 성별, 교육, 소득, 흡연, 음주 같은 공변량은 건강설문조사 부문 변수이다.
- 세 부문의 변수를 함께 사용하므로 표 6-2의 "건강설문 AND 검진 AND 영양" 행에 해당하며, 제9기(2024)의 가중치는 `tot`, 즉 `wt_tot`이다. 건강설문·검진조사 가중치(`wt_itvex`)와 영양조사 가중치(`wt_ntr`)는 한 부문의 변수만 사용할 때의 가중치이므로 사용하지 않는다.

**복합표본 설계 반영**
- 분석 시 `wt_tot` 가중치, `kstrata` 층, `psu` 집락을 모두 지정한다.
- 성별, 연령대 등 일부 집단만 볼 때도 자료를 잘라내지 않고 도메인 분석으로 진행한다.

**자료 사용 원칙**
- 한 팀에 자료 하나만 사용하며, 다른 조사 자료와 섞지 않는다.
- 원시자료는 저장소에 올리지 않고, 팀원이 각자 신청해 받아 자기 Google Drive의 `MyDrive/hdac_data/`에만 둔다.

- `wt_tot` 결측 인원: [노트북 출력]
- `HE_obe` 결측 인원(비임신자만 값이 있음): [노트북 출력]
